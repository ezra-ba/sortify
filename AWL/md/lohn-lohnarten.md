# Lohnarten
- Leistungslöhne
	- Geldakkord
	- Zeitakkord
	- Gruppenakkord
	- Prämienlohn
- Zeitlohn

## Geldakkord
- Entlohnung pro geleistete Einheit ohne Berücksichtigung der Zeit
- Berechnung
	- `Bruttolohn = Stückzahl x Lohn/Stück`

## Zeitakkord
- für jede Leistungseinheit wird die Zeit vorgegeben (Stückzeit)
	- Berechnung
		- `Akkordlohn = Stundenlohn + Akkordzuschlag`
		- ` Minutenfaktor = Akkordlohn : 60`
		- `Bruttolohn = Stückanzahl x Stückzeit x Minutenfaktor`

## Gruppenakkord
- Entlohnung mehrerer Arbeiter gemeinsam als Gruppe mit späterer Aufteilung nach einem vorgegebenen Schlüssel
	- Berechnung
		- Gruppenlohn = Einheit x Lohn/Einheit (Stück, m2, m3, ...)
		- Bruttolohn = Gruppenlohn x Stundenlohn / Summer der Stundenlöhne

## Prämienlohn
- Arbeiter erhält neben Grundlohn eine Prämie für die Leistungen, die über einer vorgegebenen Norm liegen
	- Berechnung
		- Prämie = Mehrleistung x Prämie/Stück
		- Bruttolohn = Arbeitszeit x Stundenlohn + Prämie
