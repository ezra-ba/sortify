# Unit Testing
**Error** → Kommunikations-Skills, gedanklicher Error - Lösung: Kommunikation, Weiterbildung v. Skills
  ↓
**Fault** → Fehler im Quellcode ohne Abweichung von der Spezifikation - Lösung: Codereviews, Statische Code Analyse
  ↓
**Failure** → Fehler im Quellcode mit Abweichung von der Spezifikation - Lösung: Tests 
  ↓
**Incident** → Fehler schläft beim User auf - Lösung: ITIL 

Mathematische Formale Verifikation von JKU [Link](https://risc.jku.at/)


# Layers of Software Tests
- Unit Tests = lowest layer
- Integration Tests
- System Tests = highest layer
