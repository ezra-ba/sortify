# ETM Software Solutions: Projektvorschläge

## 1. File Organizer

Downloads landen häufig mit uneinheitlichen Namen in einem unübersichtlichen Ordner. Der geplante **File Organizer** soll neue Dateien erkennen und anhand selbst definierter Regeln passende Dateinamen und Zielordner vorschlagen.

**Geplanter Ablauf:** Datei erkennen → Dateiendung und Name prüfen → Vorschlag in einem Popup anzeigen → Bestätigung abwarten → Datei umbenennen und verschieben.

Die Anwendung soll mit **C# und .NET Windows Forms** umgesetzt werden. Vorgesehen sind `FileSystemWatcher`, Regex und eine lokale Konfiguration. Persönliche Regeln und ein Verlauf sollen über die Hauptoberfläche verwaltet werden. Alle Daten bleiben lokal; KI oder Cloud-Dienste sind nicht erforderlich.

## 2. Gaming Tournament Manager

Die Organisation eines Schach- oder Gaming-Turniers erfordert Teilnehmerlisten, Paarungen, Ergebnisse und eine aktuelle Rangliste. Der geplante **Gaming Tournament Manager** soll diese Aufgaben zentral verwalten und den Turnierablauf übersichtlich darstellen.

**Geplanter Ablauf:** Teilnehmer erfassen → Turniermodus auswählen → Paarungen automatisch erstellen → Ergebnisse eintragen → Rangliste und nächste Runde berechnen.

Die Anwendung könnte ebenfalls mit **C# und .NET Windows Forms** entwickelt werden. Geplant wären eine lokale Datenspeicherung, automatische Auswertung und eine gut lesbare Turnieransicht. Spätere Erweiterungen könnten verschiedene Turniermodi, ein Zeitlimit pro Partie oder der Export von Ergebnissen sein.

## Bezug zum Programmiererberuf

Beide Vorschläge zeigen, wie aus einem Alltagsproblem eine Softwarelösung entsteht: Anforderungen analysieren, Abläufe planen, Benutzeroberflächen gestalten, Daten verarbeiten und Funktionen testen. Dadurch wird der Beruf praxisnah und verständlich vorgestellt.
