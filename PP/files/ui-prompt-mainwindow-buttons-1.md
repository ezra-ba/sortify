
# Implementierung der Buttons (Backend-unabhängig)

## Bearbeite das MainWindow wie folgt:

- Beim Button "Ordner Wechseln" soll einfach die "Standard DateiExplorer" funktion aufgerufen werden - das auswählen eines Ordners
- Bei "Target-Ordner hinzufügen" das gleiche wie beim "Ordner wechseln"-button
- "Als Standard festlegen" soll den gerade ausgewählten Target-Ordner als Standard markieren
- "Spitznamen ändern" soll die Bearbeitung des Spitznamen des ausgewählten Target-Ordners erlauben -> Schlage mir hierzu ein paar mögliche Implementierungen vor
- "Target-Order löschen" soll den ausgewählten Target-ordner aus der Liste entfernen - aus diesem grund sollte der button auch zu "Target-Ordner entfernen" unbenannt werden, damit keine verwirrung entsteht
