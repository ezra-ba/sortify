
# Popup-UI

## Erster Entwurf 
- Das Popup-UI soll nur ein kleines Fenster sein
- Selbes Farb-Theme wie das Hauptfenster

## Aufbau
- Oben soll übersichtlich und leicht erkennbar dargestellt sein, welche Datei erkannt wurde - z.B. mit "Neues Dokument! Dateiname"
- Darunter sollen ein Dropdown Menü mit den Target Ordnern sein
- Neben dem Dropdown Menü soll der Dateiname, der auch änderbar ist, angezeigt werden - also quasi den Dateipfad "simulieren"; [Dropdown]/"filename"."Dateiendung"
