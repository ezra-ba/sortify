# UI Überarbeitung

## Generelles

- Überarbeite die UI grundlegen
- Halte das Design schlicht weiß mit beige/grau Akzenten
- Es soll sich lediglich um einen "One-Pager" handeln
- Bearbeite **NUR** die UI Datei(en), keinen Backend Code oder ähnliches!

## Aufbau

- Im Oberen Bereich über die ganze Länge soll sich der "Überwachungs-Ordner" befinden. Dort wird also der genaue Dateipfad des Ordners angezeigt und ein Button, mit dem man später den Ordner wechseln kann.
- Darunter soll sich eher auf der Linken Seite ein Bereich befinden wo die Target-Ordneraufgelistet werden. Diese sollen den vollen Dateipfad sowie einen "spitznamen" (zur besseren Übersicht) besitzen.
- Auf der Rechten Seite soll ein etwas kleinerer Bereich die Verwaltung der Target Ordner darstellen. Dort sollen Buttons wie zum Beispiel "Hinzufügen", "Löschen", "Als Standard festlegen", "Spitzname ändern" (Beim Spitznamen sollt dann am besten der spitzname bei der auflistung zum bearbeiten freigegeben werden)
